# Scout + Hunter

A Node.js project for discovering, verifying, evaluating, and ranking software development opportunities.

## Features

- GitHub opportunity discovery
- Reward and currency verification
- Payment and funding checks
- Eligibility verification
- Active pull request detection
- Opportunity scoring and ranking
- Human-review decision pipeline

## Technology

- Node.js
- JavaScript
- GitHub REST API
- Axios
- dotenv

## Setup

Install dependencies:

    npm install

Create a local .env file containing:

    GITHUB_TOKEN=your_github_token

## Tests

Run:

    npm test

## Safety

The project is read-only. It does not automatically claim opportunities, submit pull requests, post comments, submit work, or make payments.

All pursuit decisions require human review.
